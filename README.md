# Almanac

Obsidian templates for the Almanac: tending life and work for balance, not productivity.

A hand-run Obsidian system for noticing where attention goes across the lasting areas of life and work (Trees), their parts (Branches), finite pieces of growth (Shoots), single actions (Tasks) and things not yet placed (Seeds). Core Obsidian only: Templates and Bases, no community plugins.

- `SETUP.md`: install and daily use (about 5 minutes)
- `Templates/`: Seed, Task, Done, Shoot, Tree
- `Bases/`: the views (Seeds, Tasks, Shoots, Trees), embedded by name
- `Tending.md`: the daily Tending page
- `obsidian-config/`: property types and a CSS snippet that hides the config folders
- `examples/`: a dummy Seed, Task, Shoot and Tree, to see the views working

**This repo holds templates, views and documentation only. Nothing personal or work-related, ever; examples are dummies with generic names.**

Versions are git tags: v2.0 (first prototype), v2.1 (from its feedback), v2.2 (after the retro).
